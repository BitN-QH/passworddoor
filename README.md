  本系统基于51单片机（REGX52.H）开发，集成矩阵键盘、红外遥控、串口通信、EEPROM存储、数码管显示、蜂鸣器报警及步进电机控制模块，实现了一套高安全性的电子密码锁解决方案。支持用户密码和管理员密码双权限管理，具备密码存储、错误锁定、紧急解锁等核心功能。
1.	密码输入：
（1）通过按下矩阵键盘的S1到S10来输入密码，在输入密码时，按键S14可以回退一个数字用于修改输入的密码，按键S15可以清空输入的密码用于清零操作。按键S16用于确认输入的密码.
（2）在密码输入正确后会驱动步进电机，实现开门的效果。
（3）在密码输入错误后，蜂窝鸣会发出错误提示声音，连续输入密码错误三次后会锁定输入界面，此时可以通过输入管理员密码来退出锁定界面。
2.	密码修改：
（1）普通用户修改：可按下左侧的独立按键K2进入修改界面，在修改界面使用矩阵键盘输入新设定的密码，按键S14可以回退一个数字，按键S15可以清空输入的密码，按键S16确认保存新密码。若不想修改密码，则可以通过按下独立键盘K4来退出修改密码界面，进入输入密码界面。
（2）管理员密码修改：按下左侧独立按键K3进入修改界面，修改过程与普通用户修改过程相同。
3.密码储存：
（1）修改后的密码会自动保存在eeprom中，故当重启或者意外断电时，密码不会损失，开机后仍可以使用。
（2）由于在第一次使用时会从eeprom读取密码（此时eeprom为保持有密码数据），会导致密码为空或者其他情况，所以在第一次使用时请修改管理员密码与普通密码。
4.串口通信：
（1）可将单片机与电脑进行连接，实现非按键通信，在串口处需注意波特率为9600，否则会造成通信异常。
（2）在串口通信时，一次只能发送一个按键信息，即需要多次发生数据才能完成相关操作，如输入密码时不能一次发送12345678（示例），而应该将密码一位一位分开，分8次发送。
5.红外通信：
（1）在使用红外遥控时，由于红外信号为连续的，如果按压时间过长会导致读取多个相同密码值，所以在按压时，应注意按压时间不宜过长。使用红外遥控时密码闪烁为正常现象，是由于红外中断处理函数耗时较长导致的。
